Installation guide

iOS & iPadOS

RoMacShade is distributed as an arm64 tweak dylib. The supported walkthrough below uses LiveContainer; other sideloading tools are linked as general resources, with compatibility depending on their current capabilities.

Download iOS v0.1.1 preview

Before you start

  • Use an iPhone or iPad and a compatible arm64 app environment.
  • Obtain the base app IPA through your own Apple account and follow the chosen sideloading tool's current instructions.
  • The current iOS release is a prerelease. The tested setup uses LiveContainer's per-app tweak support and signing flow.
Use official downloads. For each sideloading tool, follow its linked project documentation and check the current device and iOS requirements before installing.

LiveContainer setup

  1. Install and configure LiveContainer using its official installation guide.
  2. Import your own Roblox IPA into LiveContainer as described by its guide.
  3. Download RoMacShade.dylib and import it into that app's per-app Tweaks folder.
  4. In LiveContainer, open Tweaks → Sign and wait for signing to finish.
  5. Launch the app, enter a 3D experience, and open the floating RoMacShade control to select effects or presets.

If loading reports code signature invalid, use LiveContainer's Tweaks → Sign flow and relaunch. Follow the current LiveContainer tweak guide if its interface changes.

Installer compatibility: LiveContainer's guide currently lists some installation approaches as unsupported. Check its official installation page for the current status before choosing an installer.

Using an IPA outside LiveContainer

This project documents loading the tweak through LiveContainer. We do not provide instructions for injecting RoMacShade into, modifying, or re-signing Roblox's IPA. For apps you own or are authorized to modify, use Apple's supported development and code-signing tools and the app author's integration guidance.

Effects and presets

The iOS binary includes its bundled effects and presets for offline use. Browse the separate RoMacShade Effects library for release assets and library notes. Some ReShade effects may exceed the iOS runtime's supported features.
