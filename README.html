Hardware-accelerated ReShade and FX post-processing shaders on macOS Metal for Roblox.

Version 0.0.1 ✓ 100% Virus-Free & Clean Apple Silicon & Intel macOS 12.0+

🛡️ Security & macOS Gatekeeper Notice ("Is MacShade a virus?")

MacShade is completely clean, safe, and contains zero malware, spyware, adware, or trackers.

When downloading software outside the Mac App Store that is not signed with an Apple Developer Program subscription ($99/year), Apple's Gatekeeper displays a standard prompt on first launch: "“MacShade” cannot be opened because Apple cannot check it for malicious software". This is standard macOS behavior for all independent community tools, not an indication of a virus.

Method 1: Right-Click (Easiest)

1. Open your Applications folder in Finder.

2. Right-click (or Control-click) MacShade.app and choose Open.

3. In the dialog, click Open. macOS will remember your approval.

Method 2: System Settings

1. Open System Settings → Privacy & Security.

2. Scroll down to the Security section.

3. Click Open Anyway next to the MacShade notice.

Method 3: Terminal

If you prefer the command line, remove the quarantine attribute:

xattr -cr /Applications/MacShade.app

🚀 Quick Start (Zero-Terminal Setup)

  1. Drag MacShade.app into your /Applications folder from the DMG.
  2. Open MacShade from Applications (use Right-click → Open on first launch).
  3. Click the prominent button: "Launch Roblox with MacShade".
  4. MacShade automatically prepares an isolated, sandboxed host copy and launches Roblox with Metal post-processing enabled.

🎮 In-Game Controls & Features

✨ Key Architecture & Features

⚡ Real Metal Compilation

Translates ReShade FX source directly to SPIR-V, converts to MSL (Metal Shading Language), and executes native Metal raster pipelines.

🎨 17 Extravi Presets Included

Full support for popular community presets including Clear Day, Soft Cinema, Extravi Cinema, Fantasy, Vibrant, and more.

🔒 Safe Sandbox Isolation

Leaves your installed official Roblox player completely untouched. Prepares an isolated copy in Application Support.

🛡️ Hardened & Protected

Proprietary native Objective-C/Metal host launcher, encrypted string literals, and Mach-O symbol mangling.

🔧 Troubleshooting & Logs

If you encounter issues or want to view diagnostic details:

  • Logs location: Click "Logs" in the MacShade launcher or view files in ~/Library/Logs/MacShade/.
  • Shaders folder: Click "Shaders" in the launcher to drop custom .fx shaders into ~/Documents/reshade roblox.
  • Presets folder: Click "Presets" to add community .ini presets.
